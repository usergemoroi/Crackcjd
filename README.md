# Анализ и модификация Android приложения

## Описание

Данный репозиторий содержит результаты анализа Android приложения `Myapps.apk`. Приложение было создано в учебных целях для практики reverse engineering.

## Найденные компоненты

### 1. Защита приложения
- **Упаковщик**: dpt-shell 
- **Нативная библиотека защиты**: `libantidebug.so`
- **Упакованный DEX**: `assets/vwwwwwvwww/arm64/libd1b98aadffdc1f09.so`
- **Зашифрованные ресурсы**: `assets/np/*` (множество файлов)

### 2. Классы проверки лицензии

В упакованном DEX найдены следующие методы класса `SignatureChecker`:
- `checkKey` - проверка ключа
- `decryptKey` - расшифровка ключа  
- `getMasterKey` - получение мастер-ключа
- `validateLicense` - валидация лицензии

## Инструменты использованные при анализе

1. **apktool** - декомпиляция APK в smali код
2. **jadx** - декомпиляция DEX в Java код  
3. **strings** - извлечение текстовых строк
4. **unzip** - распаковка APK

## Дальнейшие шаги

Для полной модификации приложения потребуется:

1. **Распаковка dpt-shell**:
   - Извлечь реальный DEX из `libd1b98aadffdc1f09.so`
   - Расшифровать файлы в `assets/np/`

2. **Модификация проверки ключа**:
   - Найти методы `checkKey` и `validateLicense` в распакованном DEX
   - Изменить их для принятия любого ключа (возврат true)

3. **Пересборка APK**:
   - Собрать модифицированный APK с помощью apktool
   - Подписать APK для установки
